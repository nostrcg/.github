## 📝 Submitting Work Items

We welcome new ideas, proposals, and contributions to the Nostr Community Group. Before starting work on a new proposal, you may optionally wish to complete the following questionnaire and send to the mailing list:

### 📌 Work Item Questionnaire

**1. Work Item Title:**  
Provide a clear and descriptive title for your idea.

**2. Work Item Summary:**  
Briefly explain your idea in simple terms. What's the core purpose?

**3. Relation to Nostr:**  
Describe specifically how your proposal connects to The Nostr Protocol.

**4. Web & W3C Relevance:**  
Explain how your proposal intersects with the web, existing web standards, or could benefit from alignment with W3C work.

**5. Type of Output:**  
Specify the intended output, such as:
- NIP
- W3C Note
- Community Group Report
- Markdown Document
- Community Group Blog Post
- Other
- Undecided (or add more as needed)

**6. Contributors:**  
Identify who will actively contribute to developing this proposal (include yourself and ideally additional contributors).

- Contributor 1:
- Contributor 2 (optional):
- Others (optional):

**7. Source Code and Workflow:**  
Where will your source code live, and how would you prefer to collaborate?

**8. Additional Notes or Questions:**  
Include any extra context, questions, or ideas you'd like to share.
